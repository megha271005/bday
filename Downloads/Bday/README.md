## ✨ Experience & Features

| Screen / Section | Highlights & Interactions |
| :--- | :--- |
| **🌌 1. Welcome Experience** | Immersive starry sky canvas, gentle twinkling stars, floating glowing hearts, and an *"Open Your Surprise ❤️"* portal button with a cinematic dissolve transition. |
| **🎉 2. Birthday Hero** | *"Happy Birthday My Universe ❤️"* headline, large polaroid photograph, relationship statistics counter, and interactive confetti showers (*Shower Love 🎉*, *Fireworks 🎆*, *Star Shower ✨*). |
| **📸 3. Memory Gallery** | **Dual view switcher**: Interactive **3D Coverflow Carousel** (horizontal drag, card tilt, arrow key navigation) and **Polaroid Scrapbook Grid** (tilted cards, washi tape, handwritten notes, click-to-zoom lightbox). |
| **⏳ 4. Our Story Timeline** | Vertical love story milestones connected by a glowing starlight thread with pulsing heart pins (*The Day We Met*, *First Conversation*, *First Photo*, *Funniest Memory*, *Unforgettable Day*, *Today & Ahead*). |
| **🎮 Couple Quiz: "How Well Do You Know Me?"** | Romantic interactive game across 4 rounds + a special surprise question. Features 1-by-1 multiple choice, immediate animated feedback, score progress, and custom result messages based on score tiers (90-100%, 70-89%, 40-69%, <40%). |
| **💫 5. 1000 Reasons I Love You** | Large circular radial typography visualization inspired by celestial orbits. Orbiting SVG circular text paths, dynamic central counter (*"Reason No. 001"*), *Discover Another Reason*, *Surprise Me* randomizer, autoplay story mode, category filters, and **105+ unique reasons**. |
| **💌 6. A Letter From My Heart** | Realistic 3D vintage envelope with authentic wax heart seal (*"WITH LOVE"*). Clicking the seal unseals the flap with smooth paper unfolding animation, revealing stationary letter paragraphs with delicate typography and floating hearts. |
| **🔐 7. Password Vault ("Some Memories Are Just Ours")** | Authentic **3D Date Wheel Picker** to dial in your anniversary date (*March 25, 2024*), plus a passcode fallback tab (`0325`). Persistent `localStorage` unlock state, celebratory confetti, private photos, 3:00 AM whispers, and personal inside notes. |
| **✨ 8. Whispers & "Open When..." Letters** | Interactive **SVG Flashlight Mask**: hover cursor or touch across the dark starry veil to illuminate hidden love whispers. Plus interactive *"Open When..."* letters (*When You Miss Me*, *Rough Day*, *Need a Reminder*, *Can't Sleep*). |
| **🎂 9. Final Birthday Surprise** | Interactive birthday cake with glowing candles. Clicking or blowing out the candles triggers fireworks, side confetti cannons, and reveals the grand romantic message and final photo. |
| **🎵 Background Music Player** | Floating unobtrusive widget (OFF by default). Dual-engine architecture: automatically plays `public/music/birthday-song.mp3`, or falls back to an enchanting Web Audio API romantic lofi chime generator so music works out of the box! |

## 🚀 Quick Start (Run Locally)

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (version 18+ recommended).

```bash
# 1. Clone your repository (or download the ZIP)
git clone https://github.com/YOUR_USERNAME/a-little-universe.git
cd a-little-universe

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser!

## 🛠️ How to Personalize Everything

All names, dates, photos, messages, quiz questions, and passwords can be customized without touching complex code!

### 1. Names, Dates & Password
Open **[`src/data/birthdayConfig.js`](src/data/birthdayConfig.js)**:
```javascript
export const birthdayConfig = {
  boyfriendName: "His Name",
  girlfriendName: "Your Name",
  birthdayDate: "November 4", // His Birthday
  anniversaryDate: {
    year: 2024,
    month: 2, // March (0-indexed: 0 = Jan, 1 = Feb, 2 = Mar)
    day: 25,
    formatted: "March 25, 2024"
  },
  
  secretPasscode: "0325", // Passcode to unlock the secret vault
  secretDate: new Date(2024, 2, 25), // March 25, 2024
  ...
}
```

### 2. Photos & Polaroids
Simply drop your images into the **`public/images/`** folder:
- `public/images/hero.jpg` — Main hero photograph
- `public/images/memory-01.jpg` to `memory-06.jpg` — Gallery polaroids
- `public/images/memory-07.jpg` to `memory-12.jpg` — Timeline & vault photos

*(High-quality romantic placeholders are already bundled so images never appear broken!)*

### 3. Birthday Song / Music
Drop your favourite romantic song or background audio here:
- **`public/music/birthday-song.mp3`**

*(If no custom MP3 is added, the website automatically plays a soothing, built-in romantic lofi chime melody!)*

### 4. Couple Quiz Questions
Open **[`src/data/quizQuestions.js`](src/data/quizQuestions.js)** to edit, add, or reorder any of the questions, answer options, and encouraging feedback messages (*"Awww, you remembered! ❤️"*, *"Oops! Someone needs to pay more attention 😂"*).

### 5. 1000 Reasons Collection
Open **[`src/data/loveReasons.js`](src/data/loveReasons.js)** to view and edit the collection of 105+ romantic reasons across categories (*Smile & Presence*, *Personality*, *Little Habits*, *How You Treat Me*, *Memories*, *Admiration*).

## 📤 How to Upload to GitHub

### Method A: Using GitHub Desktop (Easiest & Recommended)
1. Download and install [GitHub Desktop](https://desktop.github.com/).
2. Open GitHub Desktop and click **File → Add Local Repository...**.
3. Select your project folder (`c:\Users\HP\Downloads\Bday`).
4. If prompted to create a repository, click **Create Repository**.
5. Write a commit message like `"Initial commit: A Little Universe Called Us ❤️"` and click **Commit to main**.
6. Click **Publish repository** to push it to your GitHub account (you can choose Public or Private).

---

### Method B: Using Git in Terminal / VS Code
If you have Git installed on your computer:

```bash
# 1. Initialize git
git init

# 2. Add all files (the provided .gitignore excludes node_modules automatically)
git add .

# 3. Create initial commit
git commit -m "feat: A Little Universe Called Us - Birthday Website ❤️"

# 4. Rename default branch to main
git branch -M main

# 5. Connect to your GitHub repository
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git

# 6. Push to GitHub
git push -u origin main
```

## 🌐 Free 1-Click Deployment (Vercel / Netlify)

You can host this website online for free so your boyfriend can open it on his phone or laptop from anywhere in the world!

### Deploying to Vercel (Recommended):
1. Go to [vercel.com](https://vercel.com/) and sign in with your GitHub account.
2. Click **"Add New Project"** and select your GitHub repository.
3. Vercel automatically detects **Vite**:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**. In under 60 seconds, you'll have a live, secure HTTPS URL (e.g., `https://our-universe.vercel.app`) to share with him!
